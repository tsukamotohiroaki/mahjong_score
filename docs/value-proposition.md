# このアプリが解決する課題（価値提案）

## 結論

このアプリは「麻雀のアプリ」である前に、**面倒で間違えやすい計算作業を自動化して、人が本来やりたいことに集中できるようにするアプリ**です。

麻雀はあくまで題材であり、ここで実現していること——

- 複雑なものを簡単にする
- 面倒な作業を減らす
- ユーザーの認知的な負担を減らす
- 本来の目的に集中できるようにする

——は、アプリや Web サービスを作るうえで汎用的な考え方です。このドキュメントは、麻雀を知らない人にもこのアプリの嬉しさが伝わるように、その価値を言語化したものです。

## 麻雀を知らない人向けの説明

麻雀の対局が終わると、各プレイヤーの持ち点をもとに**最終成績（順位点込みのスコア）を精算する計算**が必要になります。ボードゲームの後に「順位に応じたボーナスを加えて、全員のスコアを集計し直す」作業を想像してください。

この計算は、次のような手順を毎回・全員分こなす必要があります。

1. 4人の持ち点を順位順に並べる
2. 各プレイヤーの持ち点から基準点（返し点）を引き、1000 で割る
3. 順位に応じたボーナス（順位点）を足す
4. 全員の合計がゼロになることを確認する（ズレていたらどこかで計算ミス）
5. 同点のプレイヤーがいたら、該当順位のボーナスを均等に分け合う

慣れている人でも暗算と検算に時間を取られ、初心者はルールを覚えることと同時にこの計算も覚えなければなりません。**ゲームを楽しむためにやっているのに、いちばん時間を使うのが「計算」になってしまう**——ここが解決したい課題です。

## Before / After

| | アプリなし（手計算） | このアプリ |
|---|---|---|
| 精算計算 | 全員分を暗算・電卓で計算 | 持ち点を入力するだけで自動計算 |
| 計算ミスの検出 | 全員の合計を手で検算 | ゼロサム検証で仕組みとして防止 |
| 同点時の処理 | ルールを思い出して手で分配 | 均等分配を自動適用 |
| 対局履歴 | 紙のメモ・スマホのメモ帳 | 半荘（ラウンド）ごとに記録・一覧 |
| 必要な知識 | 計算ルールの暗記 | 不要（持ち点だけ分かればよい） |

## 計算の具体例

持ち点 25000・返し点 30000・順位点（+50 / +10 / −10 / −30）のルールで、対局結果が次のようになったとします。

| プレイヤー | 持ち点 | 計算式 | 最終スコア |
|---|---:|---|---:|
| A（1位） | 38700 | (38700 − 30000) ÷ 1000 + 50 | **+58.7** |
| B（2位） | 30100 | (30100 − 30000) ÷ 1000 + 10 | **+10.1** |
| C（3位） | 22400 | (22400 − 30000) ÷ 1000 − 10 | **−17.6** |
| D（4位） | 8800 | (8800 − 30000) ÷ 1000 − 30 | **−51.2** |

4人の合計は 0 になります（ゼロサム）。この検算まで含めて手作業でやると数分かかり、しかもミスに気づきにくい作業ですが、アプリでは持ち点 4 つを入力した瞬間に終わります。

## 何を「仕組み」で防いでいるか

このアプリの設計方針は「気をつける」ではなく「**気をつけなくても間違えられない仕組み**」です。

- **順位点の自動計算** — 順位づけ・基準点との差分・順位点の加算をすべて自動化（`app/models/game.rb` の `calculate_ranking_scores`）
- **ゼロサム検証** — ルール設定の時点で順位点の合計が理論値と一致しなければ保存できないため、「合計が合わないルール」がそもそも作れない
- **同点時の均等分配** — 該当順位のボーナスを自動で均等分配するため、人によって処理がブレない
- **4人1組のトランザクション登録** — ゲーム作成とプレイヤー登録をまとめて行い、中途半端なデータ（プレイヤーが3人しかいないゲームなど）が残らない

これにより、ユーザーの操作ミスだけでなく「設定ミス」「記録の不整合」も入り口の段階で防いでいます。

## 面接・ポートフォリオでの説明例

> 麻雀では、ゲームを楽しむために点数計算やスコアの記録が必要になります。しかし点数計算は慣れている人にとっても手間がかかり、初心者にとってはルールの理解と同時に覚えなければならない負担の大きい部分です。
>
> そこで、面倒なスコア計算をできるだけ簡単・効率的に行えるようにすることで、プレイヤーが本来楽しみたい麻雀そのものや、ルールを学ぶことに集中できるアプリを目指しました。
>
> 「計算する」という作業に必要以上にリソースを使わず、**人が本来やりたいことに集中できるようにする**ことを、このアプリの一番の目的としています。

麻雀を知らない相手には、「複雑な計算や手作業が、本来楽しみたい・学びたい部分の邪魔をする」→「そこをアプリで自動化した」という構造で説明できます。これは経費精算・割り勘・シフト集計など、あらゆる「面倒な計算」に当てはまる汎用的な課題設定です。
