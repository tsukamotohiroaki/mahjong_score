# ADR-0002: AWS の運用をやめ、家の Mac と ngrok で運用する

- ステータス: 決定
- 決定日: 2026-11-16（AWS 削除は 2026-11-22）
- 関連: [#366](https://github.com/tsukamotohiroaki/mahjong_score/issues/366) / [#363](https://github.com/tsukamotohiroaki/mahjong_score/issues/363) / [#364](https://github.com/tsukamotohiroaki/mahjong_score/issues/364) / [#365](https://github.com/tsukamotohiroaki/mahjong_score/issues/365)

## 背景

AWS（EC2 + RDS + CloudFront ×2）の費用は月約6,000円。利用は月1回程度の対局だけで、費用が見合わない。

## 決定

AWS のリソースをすべて削除し、対局の日だけ家の Mac で動かして ngrok（ローカルを外部へ中継するツール）で公開する。手順は [`docs/commands.md`](../commands.md)「リアル麻雀で使う日の起動」。

- 本番用 LIFF アプリのエンドポイントを ngrok の固定 URL に変更した。リッチメニューと共有リンクはそのまま使える
- ローカルの DB が本番データを兼ねる

## 検討した選択肢

| 選択肢 | 判断 |
|---|---|
| A. AWS を続ける | **却下**。費用が利用に見合わない |
| B. 家の Mac + ngrok | **採用**。費用ゼロ。利用者が居るときだけ動けば足りる |
| C. 無料枠のあるクラウド（Vercel + Render + Neon など） | **保留**。Mac の用意が負担になったら別 Issue で検討する |

## 結果

| 失ったもの | 内容 |
|---|---|
| 常時稼働 | Mac と ngrok が止まっている間は、公式アカウントの友だち全員が開けない |
| 戻せないもの | 本番 DB の対局データ（捨てる合意済み）、CloudFront の URL 2本、Elastic IP |

| 記録として残すもの | 理由 |
